🌱 What This Application Does

Imagine tipping a handful of dots onto a sheet of paper. Now imagine stretching a thin, bendy ribbon between those dots so that each one connects to the next in a soft, sweeping curve. That is the heart of this application.

Instead of drawing with a pencil, you draw with a seed — a plain number you type in. The application reads that number and uses it to decide where the dots land, how tightly the curves bend, what colours the lines take on, and how thick each stroke becomes. Change the number, and a completely different picture appears. Type the old number back in, and the original picture comes back, unchanged.

The result looks a bit like spun thread, a bit like a contour map, and a bit like a hand-drawn illustration from a design sketchbook. Everything happens instantly inside your web browser, and nothing is uploaded anywhere — the artwork is created on your own machine.

🎯 Repeatable by design

The same seed always produces the same artwork. Share a number with a colleague and they will see exactly what you see.

🌈 Gradient colour

Lines glide through a smooth range of hues, so each strand shifts in colour as it travels across the frame.

✏️ Variable line weight

Some strokes arrive thin and delicate, others thick and bold, building depth and a sense of movement.

🖼️ Framed output

Every study is presented inside a clean frame, ready to be captured as a reference image for your own projects.

🖱️ How to Use the Application

The interface is deliberately minimal so you can focus on the artwork rather than the controls.

  • Seed field. A number that determines the entire composition: point placement, curve shape, colour range, and line weight. Type any whole number you like.
  • Generate button. Draws the study for the seed currently in the field. If you leave the field blank, the application picks a seed for you and shows it so you can note it down.
  • Frame area. The main canvas in the centre of the page. This is where the artwork appears, inside its frame.
  • Save option. Captures the current study as an image file so you can keep it, print it, or drop it into a design document.

A productive way to work is to generate a seed, save it if you like the result, then nudge the number by one and generate again. Neighbouring seeds often produce related compositions, which makes it easy to explore a family of similar studies before settling on a favourite.

🔁 Why "Reproducible" Matters

Many generative tools give you a beautiful result you can never quite get back. This one is built around the opposite idea: every picture is tied to a number, and that number is all you need to recreate it.

That has real, practical benefits:

  • A seed written in a notebook is a permanent recipe for one exact artwork.
  • Two people on opposite sides of the world can compare the same study by swapping a number.
  • You can return to a design weeks later and continue from exactly where you stopped.
  • Colourways and compositions can be catalogued alongside the seed that produced them.

🧵 Built for Design Work

The line studies this application produces were made with surface and textile design in mind. Sweeping curved lines with soft colour gradients translate naturally into embroidery paths, printed fabric repeats, woven patterns, screen-print layers, and wall art.

Because each study is reproducible, a seed becomes a design reference. You can log a set of seeds as a small collection, revisit them when a client asks for variations, and keep the whole family visually consistent while still offering genuine difference.

🛠️ Troubleshooting

Almost every hiccup with a browser-based application is quick to fix. Try these in order.

  • Nothing happens on double-click. Right-click the index.html file and choose Open with, then select a modern browser such as Edge or Chrome.
  • The page looks blank or unstyled. Refresh the page with Ctrl + F5 to force a clean reload, clearing any stale copy from the browser cache.
  • The canvas appears empty. Make sure you have typed a seed and pressed the generate button. A blank seed field may simply be waiting for input.
  • Lines look jagged or cut off. Maximise the browser window so the frame has enough room, and check that your browser zoom is set to 100 per cent.
  • The download did not complete. Revisit the download page and save the project folder again, ideally to a folder outside any cloud-synced directory.
  • Something still will not work. Update your browser to the newest version, then try again. Out-of-date browsers are the single most common cause of display problems.
